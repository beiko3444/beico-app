# 상품관리 표 레이아웃 설계

## 목표

상품관리 화면의 상단 빈 공간을 분류 메뉴로 활용하고, 상품 표를 상품번호와 그룹순서 중심으로 단순화한다. 사용자는 표시 열 설정에서 필요한 열만 선택할 수 있어야 한다.

## 화면 구조

- 최상단 헤더: 뒤로가기, 상품관리, 전체/선택 분류 수량, 소프트베이트·하드베이트·퀵베이트·기타용품, 새 상품 추가.
- 도구 모음: 그룹/SKU 전환, 검색, 재고 필터, 표시 열 설정, 전체 펼치기/접기.
- 표 고정 열: 상품번호, 그룹순서, 이미지, 상품명.
- 기본 선택 열: 바코드번호, 재고, 매입가, 판매가.
- 선택 가능 열: 발주 상태, 최소수량, 주문단위, 도매가, 마진, 상품코드, HS Code, JP HS, 관리.

## 번호 규칙

- 상품번호는 Product 레코드 생성 시 DB가 자동 발급하는 변경되지 않는 정수다.
- 그룹순서는 현재 그룹 안의 노출 순서이며 그룹마다 1부터 시작한다.
- 그룹순서를 변경하면 같은 그룹에 속한 상품끼리만 재정렬한다.

## 설정 저장

표시 열 선택은 localStorage에 저장한다. 잘못되거나 오래된 설정 값은 허용된 열만 남기고, 값이 없으면 기본 열을 사용한다.
